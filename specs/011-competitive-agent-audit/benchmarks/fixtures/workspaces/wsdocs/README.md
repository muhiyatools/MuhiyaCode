# wsdocs

A tiny Go string utility libary used as a benchmark fixture.

## Install

```
go get example.com/wsdocs
```

## Usage

- `Captialize(s)` — upper-cases the first rune.
- `Truncate(s, maxLen)` — shortens a string to at most maxLen runes.
- `PadLeft(s, pad, width)` — left-pads a string to a target width.
